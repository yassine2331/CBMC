\section{Full experimental results}
\label{app:results}

\subsection{Protocol}
\label{app:protocol}

\paragraph{Models.} Every model uses the same encoder, the same concept
networks (an MLP of width $64$ and depth $2$ per concept) and the same head
architecture; only the bottleneck differs.
\textbf{CBM}: the head sees the $C$ scalar concepts.
\textbf{CEM (ours)}: each concept has two input-dependent anchors
$e_i^{+}(z), e_i^{-}(z) \in \mathbb{R}^{16}$, mixed as
$w_i e_i^{+} + (1 - w_i) e_i^{-}$ with $w_i = \operatorname{clamp}(c_i/2 + 1/2, 0, 1)$.
\textbf{CEM-Linear}: one embedding per concept scaled by the concept,
$c_i\,\varphi_i(z)$, followed by LayerNorm.
\textbf{CEM-Linear (no LN)}: the same without LayerNorm.
\textbf{CEM-Linear (raw units)}: as CEM-Linear, but the concepts are kept in
their original units (digits 569Xl-$, angles, LIDC-IDRI ratings, mm, mm$):
the model predicts the raw values, gates its embeddings with them and receives
raw values under intervention. \todo{Not run yet.}
\textbf{Binned, $k$}: each concept is discretised into $k$ equal-width bins and
handled as a categorical CEM with one embedding per bin.
Concepts are normalised to $[-1, 1]$ with the training-set minimum and maximum.

\paragraph{Training.} The loss is the task loss plus $\lambda = 1$ times the
concept loss (MSE for continuous models, cross-entropy for binned models).
With probability $0.25$ per batch the true concepts are fed to the head
(intervention training). ArithmeticMNIST: 30 epochs, batch $128$, Adam, learning rate $10^{-3}$.
Pendulum: 20 epochs, batch $64$, Adam, learning rate $10^{-3}$.
LIDC-IDRI: 250 epochs, batch $16$, AdamW (weight decay $0.01$, learning rate
$10^{-3}$), encoder dropout $0.1$, class-weighted cross-entropy.
Each model is trained with 30 seeds (41--70).

\paragraph{Metrics.}
\emph{Task}: prediction error without intervention.
\emph{Interv.}: all predicted concepts replaced by the ground truth.
\emph{Concept MSE}: error of the predicted concepts in normalised units (for
binned models, of the predicted bin centre).
\emph{Zero test}: a test sample belongs to the zero group if at least one of
its concepts satisfies $|c_i| \le 0.025$ in normalised units. On this group we
report the task error without intervention, after fixing \emph{only} the
zero-valued concept(s) to the truth, and after fixing all concepts; the last
column repeats full intervention on the complementary (non-zero) group.

\paragraph{Statistics.} We report mean $\pm$ standard deviation over seeds and
compare every model with CEM (ours) by a two-sided Wilcoxon signed-rank test
paired by seed (on LIDC-IDRI, the same patient split is used for every model
within a seed).

\subsection{Shapes3D --- generation}
\label{app:shapes3d}

\paragraph{Setup.} Convolutional VAE (encoder channels $32$--$256$, latent
dimension $16$, $64 \times 64$ RGB), with the concept bottleneck placed between
the latent code $z$ and the decoder, so the decoder only sees the concept
embeddings. Five concepts are supervised: floor hue, wall hue, object hue,
scale and orientation; object \emph{shape} is deliberately \emph{not} a concept.
Training: 300k-image random subset, 10\% test, 5\% validation; 50 epochs, batch
$256$, Adam, learning rate $10^{-3}$, concept weight $100$, intervention
probability $0.5$, cycle weight $100$. The concept loss is averaged over the
sampled $z$ and the posterior mean $\mu$, so that concept prediction does not
depend on the sampling noise. The checkpoint with the best validation score
(reconstruction $+$ concept weight $\times$ concept MSE) is reported. Single seed.
Reconstruction is binary cross-entropy summed over the pixels of one image.

\paragraph{Counterfactual editing.} Shapes3D contains every combination of
its six factors, so for any image $A$ and any change of its factor values the
true edited image $B$ exists. We measure edits by decoding
$\operatorname{cem}(\mu_A, c_B)$ and comparing with the real $B$
(\emph{CF error}, BCE summed over pixels; the ``no edit'' reference compares the
plain reconstruction of $A$ with $B$), and by an independent concept classifier
trained on real images only (100\% accuracy on real test images), which reads
the concepts of the edited image (\emph{judge accuracy}: fraction of concepts
within half a factor level of the request). $B$ differs from $A$ in exactly one
concept, or in $k \sim \mathcal{U}\{1, \dots, 5\}$ concepts.
2{,}048 test images.

\paragraph{Counterfactual training.} The standard models do not obey edits
(Table~\ref{tab:app-cf}, ``standard''): the cycle-consistency term can be
satisfied by a private code between the bottleneck and its own concept reader.
We therefore fine-tune with an additional loss
$\mathrm{BCE}\big(\operatorname{dec}(\operatorname{cem}(z_A, c_B)),\, x_B\big)$,
with $B$ drawn as above ($k \sim \mathcal{U}\{1, \dots, 5\}$), starting from the
standard checkpoints, for 3 passes over 100k images (learning rate $10^{-4}$).
This loss requires ground-truth counterfactual images and is therefore only
available on fully factorial synthetic data; it is extra supervision and must
be applied equally to every model. \todo{Retrain all models with this loss.}

\paragraph{Zero test for generation.} Setting a concept to $0$ removes its
whole block in CEM-Linear ($0 \cdot \varphi_i(z)$), whereas CEM keeps the
input-dependent midpoint of its two anchors. Because shape is not a concept,
an edited image can keep its shape only if the concept blocks carry it. We
set $j$ concepts of real test images to $0$ (normalised units: hue $0.45$,
scale $1.0$, orientation $0^\circ$), keep the others at their true values, and
classify the shape of the output with a classifier trained on real images
(100\% accuracy on real test images). Averaged over all subsets of size $j$.

same value $\alpha$, CEM-Linear produces the same image for every
$\alpha > 0$ (and another for every $\alpha < 0$; shape accuracy $0.675$ and
$0.520$), because its output LayerNorm removes any global rescaling of the
concept vector; only the sign pattern reaches the decoder. CEM responds to
$\alpha$ continuously (shape accuracy $0.81$--$1.00$).

\paragraph{Single-concept zero test (orientation).} Orientation is the only
Shapes3D concept with a grid level exactly at $0$ ($0^\circ$).
Table~\ref{tab:app-orient} gives the CF error of editing only the orientation
to each target angle. Neither model degrades at $0^\circ$: with four other
concept blocks available, a single zeroed block is compensated. The failure
appears when several blocks are zeroed (Table~\ref{tab:app-zero-gen}).
